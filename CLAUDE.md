# Start here

Read HANDOFF.md first: what the project is, its current state, how to run and release it, how the author likes to
work, and what is open. SPEC.md is the product spec; docs/portfolio/ITERATIONS.md is the history.

# UI work

Before adding or changing any screen or control, read COMPONENTS.md and reuse the patterns in it. Do not add a
second way of doing something that already has one (for example a "close" button: going back is the chevron).
